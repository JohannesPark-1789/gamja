# 엄마 녹음기 (안드로이드)

버튼 하나로 **누르면 녹음 시작 → 다시 누르면 멈춤 → 자동으로 구글 드라이브에 저장**되는 아주 단순한 녹음 앱입니다.
전자기기가 익숙하지 않은 어르신이 쓰시도록, 화면에는 큰 버튼 하나와 상태 문구만 있습니다.

## 화면

- 빨간 큰 버튼 **"녹음"** → 누르면 녹음 시작, 위에 `녹음 중 03:12` 처럼 시간이 크게 표시됨
- 회색 큰 버튼 **"멈추기"** → 누르면 녹음 종료, 바로 드라이브 업로드 시작
- 아래 상태 문구
  - `✓ 녹음은 모두 구글 드라이브에 저장됐어요` (초록)
  - `구글 드라이브에 저장하는 중… (2개)` (주황)
- 손이 떨려 두 번 눌리는 것을 막기 위해 1.5초 안의 연속 터치는 무시합니다.
- 녹음 중에는 화면이 꺼지지 않고, 홈 버튼을 눌러도 녹음은 계속됩니다(알림창에 "녹음 중입니다" 표시).

## 동작 방식

| 항목 | 내용 |
|---|---|
| 마이크 | USB / 유선 외부 마이크가 꽂혀 있으면 자동으로 그 마이크를 사용. 없으면 태블릿 내장 마이크 |
| 녹음 형식 | `.m4a` (AAC 128kbps, 모노) — 1분에 약 1MB |
| 파일 이름 | `녹음_2026-10-25_14-30-05.m4a` |
| 저장 위치 | 구글 드라이브의 **`엄마 녹음`** 폴더 (없으면 자동 생성) |
| 인터넷이 끊기면 | 태블릿에 보관해 두었다가 인터넷이 연결되면 자동 업로드 |
| 태블릿 사본 | 업로드가 끝난 파일도 태블릿 앱 폴더(`uploaded/`)에 사본이 남습니다 |
| 드라이브 권한 | `drive.file` — 이 앱이 만든 파일/폴더에만 접근 (다른 드라이브 파일은 볼 수 없음) |

폴더 이름을 바꾸려면 `app/src/main/java/com/gamja/recorder/DriveUploader.kt` 의 `FOLDER_NAME` 을 수정하세요.

## 보호자용 설치 방법 (처음 한 번만)

구글 드라이브 업로드를 위해 **Google Cloud 에 이 앱을 등록**하는 과정이 한 번 필요합니다. (무료)

### 1. 앱 빌드하기 (PC)

1. [Android Studio](https://developer.android.com/studio) 설치
2. `recorder_app` 폴더를 Android Studio 로 열기
3. 터미널에서 서명 키의 SHA-1 확인:
   ```bash
   ./gradlew signingReport
   ```
   `Variant: debug` 아래의 `SHA1: AB:CD:...` 값을 복사해 둡니다.

> ⚠️ 구글에 등록한 SHA-1 과 실제 설치한 APK 의 서명이 같아야 합니다.
> **같은 PC 에서 빌드한 APK** 를 설치하세요. (다른 PC 에서 빌드하면 SHA-1 이 달라 드라이브 연결이 실패합니다)

### 2. Google Cloud 설정

[Google Cloud Console](https://console.cloud.google.com/) 에서:

1. **새 프로젝트** 만들기 (이름 아무거나, 예: `엄마녹음기`)
2. **API 및 서비스 → 라이브러리** → `Google Drive API` 검색 → **사용**
3. **API 및 서비스 → OAuth 동의 화면**(Google 인증 플랫폼)
   - 사용자 유형: **외부**
   - 앱 이름, 지원 이메일 입력 후 저장
   - **게시 상태를 "프로덕션"으로 변경(앱 게시)** 하세요.
     "테스트" 상태로 두면 7일마다 연결이 끊길 수 있습니다.
     이 앱이 쓰는 `drive.file` 권한은 민감하지 않은 권한이라 별도 심사 없이 게시됩니다.
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **Android**
   - 패키지 이름: `com.gamja.recorder`
   - SHA-1 인증서 디지털 지문: 1단계에서 복사한 값
   - 만들기

코드에 클라이언트 ID 를 넣을 필요는 없습니다. (패키지 이름 + SHA-1 로 자동 인식)

### 3. 갤럭시탭에 설치

1. 갤럭시탭 **설정 → 휴대전화(태블릿) 정보 → 소프트웨어 정보 → 빌드번호** 7번 터치 → 개발자 옵션 → **USB 디버깅** 켜기
2. USB 로 PC 와 연결 후 Android Studio 에서 ▶ 실행 (또는 `./gradlew installDebug`)

### 4. 태블릿에서 첫 설정

1. 앱 실행 → **마이크 / 알림 권한 허용**
2. 화면 아래 **"구글 드라이브 연결하기 (보호자용)"** 버튼 → 녹음을 저장할 구글 계정 선택 → 허용
   - 연결이 끝나면 이 버튼은 사라집니다.
3. 짧게 한 번 녹음해 보고, 드라이브에 `엄마 녹음` 폴더와 파일이 생겼는지 확인
4. 마이크를 꽂은 상태에서 녹음하면 화면 아래 작은 글씨로 `마이크: (마이크 이름)` 이 표시됩니다. 외부 마이크가 맞는지 확인하세요.

### 5. 어머니가 쓰시기 편하게 (권장)

- **배터리 최적화 해제**: 설정 → 애플리케이션 → 녹음기 → 배터리 → **제한 없음**
  (삼성 기기는 배터리 절약 때문에 백그라운드 업로드가 늦어질 수 있습니다)
- 홈 화면 **첫 화면 가운데**에 `녹음기` 아이콘만 크게 두기
- 화면 자동 꺼짐 시간을 길게 (설정 → 디스플레이 → 화면 자동 꺼짐)
- 꼭 이 앱만 쓰시게 하려면 **설정 → 보안 → 앱 고정** 기능도 쓸 수 있습니다

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "드라이브 연결이 필요해요" 가 계속 나옴 | Cloud 콘솔의 패키지 이름/SHA-1 이 맞는지, Drive API 가 사용 설정됐는지, 동의 화면이 프로덕션인지 |
| "저장하는 중…" 숫자가 줄지 않음 | 와이파이 연결, 배터리 최적화 해제 여부 |
| 외부 마이크가 아닌 내장 마이크로 녹음됨 | 마이크를 먼저 꽂은 뒤 녹음 버튼 누르기. 화면 아래 `마이크:` 표시 확인 |

## 구조

```
app/src/main/java/com/gamja/recorder/
├── MainActivity.kt      화면 (큰 버튼 하나), 권한 요청, 드라이브 계정 연결
├── RecordingService.kt  포그라운드 서비스에서 MediaRecorder 로 녹음, 외부 마이크 우선 선택
├── UploadWorker.kt      WorkManager — 인터넷 연결 시 대기 중인 파일을 모두 업로드, 실패 시 자동 재시도
├── DriveUploader.kt     Google Drive REST API v3 (폴더 생성 + resumable 업로드)
├── DriveAuth.kt         Google Identity AuthorizationClient 로 drive.file 권한/토큰 획득
└── AppState.kt          상태(StateFlow), 파일 위치, 설정 저장
```
